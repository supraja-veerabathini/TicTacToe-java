# 🎮 Tic Tac Toe – Java Console Game

A simple, interactive, two-player Tic Tac Toe game developed using **Core Java**. This project brings the classic 3×3 Tic Tac Toe game to the command line, allowing two players to compete by taking turns and trying to get three marks in a row.

## 📌 Project Overview

Tic Tac Toe is a classic strategy-based game played between two players on a 3×3 grid. Players take turns marking empty cells with **X** and **O**. The first player to align three marks horizontally, vertically, or diagonally wins the game.

This project demonstrates the practical implementation of Java fundamentals, logical thinking, conditional statements, loops, and arrays.

## ✨ Features

- **Two-Player Gameplay:** Allows two players to play against each other.
- **Interactive Console:** Displays the game board and accepts player moves through the command line.
- **Turn-Based System:** Players alternate turns between X and O.
- **Winning Condition:** Detects horizontal, vertical, and diagonal winning combinations.
- **Draw Detection:** Identifies when the board is full and no player has won.
- **Simple Interface:** Easy-to-understand console-based gameplay.

## 🎯 Game Rules

1. The game is played on a 3×3 grid.
2. Two players participate: Player 1 (X) and Player 2 (O).
3. Players take turns selecting an available position.
4. A player wins by placing three marks in a horizontal, vertical, or diagonal line.
5. If all nine positions are filled without a winner, the game ends in a draw.

## ▶️ How to Run the Project

**Prerequisites**
- Java Development Kit (JDK) installed.
- Eclipse IDE or any Java-supported IDE.

**Steps**

1. Clone this repository:

   ```bash
   git clone https://github.com/supraja-veerabathini/TicTacToe-java.git
   ```

2. Open Eclipse IDE.
3. Select **File → Import → Existing Projects into Workspace**.
4. Browse to the cloned project folder.
5. Open the `src/com/TicTacToe` package.
6. Locate the Java file containing the `main()` method.
7. Right-click the file and select **Run As → Java Application**.
